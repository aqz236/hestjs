# ✨ HestJS 框架介绍

HestJS 是一个基于 Hono 和 Bun 打造的现代化 TypeScript 后端框架，致力于为开发者提供类似 NestJS 的开发体验，同时拥有更高性能和更轻量的架构。HestJS 支持模块化、依赖注入、装饰器路由、自动 OpenAPI 文档生成等特性，适合构建高性能 API 服务和微服务应用。

## 主要特性

- 🎯 类 NestJS 语法，易于上手
- ⚡ 极致性能，基于 Hono+Bun
- 📚 自动生成 OpenAPI 3.0 文档
- 🎨 集成 Scalar，现代化 API 文档界面
- 🔧 完整 IoC 容器支持
- 🛡️ TypeScript 类型安全
- 🚀 快速开发与热重载

## 适用场景

- 构建高性能 RESTful API
- 微服务架构
- 需要自动化 API 文档的项目
- 追求开发效率与类型安全的团队

> HestJS 让 TypeScript 后端开发变得更简单、更高效、更美观。
